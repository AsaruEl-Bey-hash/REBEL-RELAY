# REBEL RELAY roster

Six agents work as a coordinated AI newsroom team. R3ALITY CHECK is their shared mentor-led evidence workflow: each agent checks claims from its own desk, while ECHO specializes in verification and media provenance. Each JSON profile includes mission, traits, strengths, watchouts, realistic voice direction, ElevenLabs settings, skills, tool allowlist, and a consistent relay format. Edit the profiles or apply local overrides; tool availability and role boundaries remain explicit.

Voice IDs are configurable per account. Suggested IDs/names are starting points from the Counter Culture News prototype and must be verified in the connected ElevenLabs account before deployment.
