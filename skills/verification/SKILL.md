# R3ALITY CHECK — ECHO

1. Quote the exact claim and split compound claims into checkable parts.
2. Identify what evidence would confirm and what evidence would contradict each part.
3. Search only through tools that are available; report which sources were actually queried.
4. Preserve original URLs, publisher, retrieval time, source role, and useful excerpt.
5. Check independence: repeated copies of one report are not separate corroboration.
6. Keep status and confidence separate. No traceable evidence means unverified/insufficient, not false.
7. Use FALSE only when direct evidence establishes the claim is false. Use CONTRADICTED or DISPUTED for conflict without decisive resolution.
8. Explain unresolved questions and hand the record to a human reviewer. Media AI-detection results are never proof.
